# Daily workspace refinement

## Goal
Make the Command Center, Department Center, and task board feel like a single clear operating flow without repeating the same queues, links, or choices.

## Changes
1. Keep the Command Center focused on the personal daily checklist: today first, later work second, with expandable task context.
2. Keep the Department Center focused on a lead’s department: priorities, pending work, approvals, and department actions.
3. Remove duplicated department task and document summaries from the Department Center when direct actions already provide those destinations.
4. Simplify the task board controls with one department filter, a clear result count, and a less visually busy default list view; retain the board for workflow management.
5. Simplify navigation labels so Command Center, Department Center, and Tasks have distinct purposes.

## Technical details
- No workflow, database, permission, or task-record changes.
- Existing task completion, expandable task context, project links, approval routing, and department access remain intact.
